# 🚀 智能域名搜索系統

一套完整的自動化域名搜索與評估系統，整合阿里云域名查詢API，批量掃描潛在精品域名。

## ✨ 主要特點

- 🔥 **多線程併發**：5個線程並發運行，速度提升3倍
- 🛡️ **智能重試機制**：自動處理API限流，最多重試5次
- 💾 **斷點續傳**：隨時停止，下次自動從上次位置繼續
- 📊 **即時輸出**：發現可購買域名立即顯示和保存
- 🎯 **智能評分**：6個維度浮點數評分系統（總分100.0）
- 💰 **盈利預測**：根據評分預測轉售倍數（3-20倍）

## 🎯 評分系統

系統採用多維度評分機制（總分100分）：

| 維度 | 分數 | 說明 |
|------|------|------|
| 域名長度 | 20分 | 越短分數越高 |
| 續費成本 | 15分 | 價格越低分數越高 |
| 行業價值 | 25分 | AI、NFT等熱門關鍵詞 |
| 品牌適配性 | 15分 | 易記、易讀、易拼 |
| 後綴價值 | 15分 | .com > .io > .co > .net > .org |
| 市場流通性 | 10分 | 數字組合、熱門詞彙 |

**精品域名標準**：總分≥70分且價格<¥100

## 🚀 快速開始

### 1. 安裝依賴

```bash
pip install -r requirements.txt
```

### 2. 配置阿里云API

編輯 `multi_thread_search.py`，填入你的阿里云API憑證：

```python
ACCESS_KEY_ID = 'your_access_key_id'
ACCESS_KEY_SECRET = 'your_access_key_secret'
```

### 3. 開始掃描

```bash
python multi_thread_search.py
```

## 🔧 系統優化

### API限流處理（已優化）

✅ **智能重試機制**：遇到限流自動重試（最多5次）  
✅ **指數退避策略**：等待時間逐次增加（4秒→8秒→16秒→32秒→60秒）  
✅ **基礎延遲**：每次請求前自動延遲0.8秒  
✅ **錯誤檢測**：自動識別限流錯誤並處理  

### 線程配置

當前配置：5個線程（已優化，避免頻繁限流）

如需調整，編輯 `multi_thread_search.py`：

```python
hunter.run_search(max_workers=5)  # 改為3、7、10等
```
